# 🌸 My Planner

A simple, free school planner that works like a real app, no login, no subscription.

**How to use it:** open the link, fill it in. Your data saves automatically in your browser (only on that device — use the 💾 button to back up or move it elsewhere).

**Features:** schedule, contacts, notes, to-do, assignment tracker, reading list, stickers, and 3 themes.

**Bulk-add your lessons:** on the schedule page, add lessons in one go instead of one at a time:
```
Math | Mon,Wed | 10:00-11:30 | 204
```

No setup needed for using the site — just open it and go.

# 🌸 Minu Päevik

Lihtne ja tasuta koolipäevik, mis toimib nagu päris äpp, ilma sisselogimise ja tellimuseta.

**Kasutamine:** ava link ja täida. Sinu andmed salvestuvad automaatselt sinu brauserisse (ainult sellesse seadmesse — kasuta 💾 nuppu varundamiseks või andmete mujale viimiseks).

**Funktsioonid:** tunniplaan, kontaktid, märkmed, tegevused, ülesannete jälgija, lugemisnimekiri, kleebised ja 3 teemat.

**Tunniplaani hulgi lisamine:** tunniplaani lehel saad lisada tunde korraga ükshaaval lisamise asemel:
```
Matemaatika | E,K | 10:00-11:30 | 204
```

Kasutamiseks pole vaja midagi seadistada — ava lihtsalt leht ja hakka pihta.
